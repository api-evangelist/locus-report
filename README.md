Locus provides property record data, aggregating zoning, permits, tax records, flood maps, and development information from public sources. Users can query an address to receive verified, cited details about parcels, tax history, appeal windows, environmental records, and nearby projects. The service offers free scans, monthly area updates, and API access for agents and developers to integrate property insights into workflows.

**Areas:** Property · Data · API · RealEstate · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Locus: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
